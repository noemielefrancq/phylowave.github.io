Get started


Overview
This is a web-based implementation of Phylowave. It enables you to load a time-resolved phylogeny, compute the phylowave index, and explore the dynamics on a browser.
Importantly, your data will stay on your computer, the analysis runs locally, in your browser.
Running time: for small trees, output is computed withing seconds. For larger tree (up to 5,000 tips), a few minutes might be required.

Step-by-step guide
Follow this step by step guide to run your analysis.
  1. Data input
    • Tree (mandatory):
      Load your time-resolved phylogeny, using the drop area. Make sure you select the correct tree format before dropping your tree. The code assumes a time-resolved phylogeny, if you input a mutation-calibrated phylogeny, the results will make little to no sense.
    • Metadata (optional):
      Has to be loaded after the tree. It will be used to (i) scale the tree in calendar time and (2) colour the results by the sequence metadata you input. This is optional, by default the tree will be scaled compared to the root (time 0), and one color will be used.
      You have two options: either parse metadata from your tip labels, or drop a metadata table and parse it according to its format.
      You can upload your metadata after running the analysis, and change the colouring scheme if needed.
  2. Parameter input
    • Pathogen specific:
      • Genome length:
        • Genome length of the pathogen, in number of base pairs. It does not need to be exact. For example for SARS-CoV-2: 30000.
      • Substitution rate:
        • Mean substitution rate of the pathogen, in substitutions per base pair per year. It does not need to be exact. For example for SARS-CoV-2: 8.1E-4.
    • Index specific:
      • Timescale:
        • Scaling factor for the index computation, in years. This is the most important parameter. As a rule of thumb, set it to an estimated minimum time it could take for a lineage of your pathogen to replace the population. For example for SARS-CoV-2: 0.15 years (which is 1.8 months). You can modify it and rerun the analysis if needs be.
      • Window:
        • window of time, in years, around each node for which other nodes are considered to circulate 'at the same time'. If \(t_i\) is the time of node \( i \), all nodes that fall in the time interval \([t_i – window; t_i + window]\) are considered to be circulating at the same time as \( i \). For example for SARS-CoV-2: 0.04 years (which is 15 days). You can modify it and rerun the analysis if needs be.
  3. Run your analysis.
    4. Simply press the "Run analysis" button. Depending on the size of your tree, the index computation can take up to a few minutes (but usually seconds).
  4. Explore dynamics
    • Tree and index dynamics
      • The results will be plotteed in the two panels "Tree" and "Index dynamics". Those are interactive, you can zoom in/out, select a tip to highlight.
    • Update parameters
      • You can explore the influence of parameters, especially Timescale and Window, on the computation of the index dynamics.
    • Colour the tree by some metadata
      • If you haven't loaded any data, all the terminal nodes will be plotted in blue. If you want to colour them by some other tip trait, you can load some metadata. You can also change the tip trait you want to colour the plots by, without reruning the whole analysis.
  5. Download results
    6. You have the option to download the index dynamics as csv by clicking on the button "Download phylowave dynamics as csv".

Going beyond
This website aims to make exploratory analysis using Phylowave more accessible, by computing in real time the Phylowave index dynamics on a tree. If you're interested in learning more about Phylowave and possible analyses, read the Phylowave paper.
Lineage detection is currently not supported by this website. To perform lineage detection based on the index dynamics, please go to the R implementation of Phylowave.
